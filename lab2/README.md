# Лабораторная работа № 2 — камера и освещение

Савицкас Р.А., М8О-306БВ-24. Вариант 8 — цилиндр.

C++20, Vulkan, GLFW и Dear ImGui; на macOS — MoltenVK.
Основа — код `../lab1` на базе стартового проекта преподавателя.

## Реализация

- Один цилиндр: 50 точек на окружности основания, 200 треугольников.
  Процедурные нормали боковой поверхности и крышек различаются на ребре;
  для этого 102 геометрические позиции представлены 202 вершинами.
- Камера: положение, поворот и угол обзора через ImGui.
- Материал Блинна–Фонга: альбедо, цвет блика и коэффициент shininess.
- Редактируемые ambient и направленный источник света.
- Доп. 1: `set = 0` содержит UBO сцены и два SSBO источников;
  `set = 1` — матрицу модели и материал.
- Доп. 2: добавление, удаление и настройка точечных источников.
- Доп. 3: добавление, удаление и настройка прожекторов с внутренним
  и внешним полууглами. Между углами — мягкая граница;
  при равных углах граница резкая.
- Доп. 4: неосвещаемые кубы цвета источников и белые линии конуса
  прожектора; общий переключатель показа визуализации.

Освещение вычисляется во фрагментном шейдере в мировых координатах.
Для точечных источников и прожекторов применяется `1 / max(distance², 0.01)`;
ограничение защищает от деления на ноль. Мягкость прожектора задаёт
`smoothstep(cos(outer), cos(inner), dot(-L, direction))`.
SSBO содержат массивы без фиксированной длины и расширяются при добавлении света.

## Сборка и запуск

На macOS нужны Xcode Command Line Tools и Python 3 с pip.
Для скачивания отсутствующих зависимостей нужен интернет;
библиотеки устанавливаются локально в проект.

```bash
cd ~/cg/lab2
./scripts/build.sh
./scripts/run.sh
```

Сборка запускает тесты геометрии, нормалей, матриц и камеры.
Для запуска двойным щелчком используйте `Start Lab.command`.

Вкладки **Camera**, **Material**, **Lights** содержат параметры задания.
В списках света **Add** добавляет источник, **Remove** удаляет выбранный,
**Selected** выбирает источник. **Show light sources** показывает или скрывает
кубы и конусы, не отключая освещение.
