# Лабораторная работа № 1 — основы 3D-графики

**Савицкас Р.А., М8О-306БВ-24. Вариант 8 — цилиндр.**

Приложение на C++20, Vulkan, GLFW и Dear ImGui, основанное на
[стартовом проекте преподавателя](https://github.com/vladeemerr/vulkan-starter-app).
На macOS Vulkan работает через MoltenVK.

## Условие и дополнительные задания

| Пункт | Реализация |
|---|---|
| Вариант 8 | Замкнутый цилиндр с 50 точками на окружности каждого основания |
| Доп. 1 | Переключение Perspective / Orthographic |
| Доп. 2 | Изменение Position, Rotation и Scale по трём осям |
| Доп. 3 | Движение по пространственной восьмёрке с вращением; Play / Pause и настройка скорости, радиуса, высоты и вращения |
| Доп. 4 | Выбор цвета объекта через ImGui ColorEdit3 |
| Доп. 5 | Процедурный цвет каждой вершины умножается на выбранный цвет объекта |
| Доп. 6 | От одного до трёх объектов с отдельными uniform buffers и VkDescriptorSet |

Радиус цилиндра — 1, высота — 2. Сетка содержит 102 вершины, 200 треугольников
и 600 индексов: два обода по 50 точек и два центра оснований.

В панели выберите проекцию, число объектов (Count) и нужный Cylinder 1 / 2 / 3.
Положение, поворот, масштаб и цвет применяются к выбранному объекту.
Play / Pause управляет анимацией; Speed, Radius, Height и Spin задают её параметры.

## Сборка и запуск на macOS

Нужны macOS 12+, Xcode Command Line Tools, Python 3 с pip и интернет для первой
сборки. Компилятор устанавливается командой `xcode-select --install`.

Из папки проекта выполните:

```bash
./scripts/build.sh
./scripts/run.sh
```

Скрипт сборки загружает закреплённые версии библиотек в `.deps/` и `third_party/`,
собирает шейдеры и приложение, запускает CTest. Python используется
вспомогательными скриптами; графическое приложение написано на C++20.

Для следующих запусков достаточно `./scripts/run.sh`. После изменения исходников
повторите сборку. Для запуска двойным кликом используйте `Start Lab.command`.

## Структура проекта

- `src/cylinder.hpp` — вершины, цвета и треугольники цилиндра.
- `src/math.hpp` — матрицы преобразований, камеры и проекций.
- `src/scene.hpp` — параметры объектов и время анимации.
- `src/application.cpp` — интерфейс и управление сценой.
- `src/renderer.cpp` — Vulkan-отрисовка, буферы и наборы дескрипторов объектов.
- `src/graphics_internal.cpp` — инициализация Vulkan, swapchain, синхронизация и ImGui.
- `src/main.cpp` — окно и цикл приложения.
- `shaders/cylinder.vert`, `shaders/cylinder.frag` — преобразование вершин и цвет.
- `tests/core_tests.cpp` — проверки геометрии, матриц и анимации.
- `report/output/Савицкас_ЛР1_вариант8.pdf` — отчёт для сдачи.

Лицензия и уведомление исходного проекта сохранены в `LICENSE` и `NOTICE`.
Зависимости перечислены в `third_party/README.md`, их лицензии — в `third_party/licenses/`.


Готовая сборка для этого Mac находится в `build/cg_lab1`; запуск — `./scripts/run.sh`.
Библиотеки в `third_party/` и Vulkan в `.deps/` сохранены локально для работы программы и пересборки.
